## 📖 Описание проекта

**Shop API** — это полнофункциональное REST API для интернет-магазина, разработанное на Django REST Framework. Проект реализует все основные функции электронной коммерции: управление каталогом товаров, категориями, корзиной покупок и пользовательской аутентификацией.

Проект создан в рамках тестового задания для позиции Backend Django Developer и демонстрирует:
- Архитектурные навыки проектирования REST API
- Работу с Django ORM и моделями данных
- Реализацию бизнес-логики электронной коммерции
- Безопасность и аутентификацию пользователей
- Документирование API и написание тестов

## 🚀 Функционал

### ✅ Реализованные возможности

#### 1. **Управление каталогом товаров**
- **Категории и подкатегории**:
  - Иерархическая структура (многоуровневые категории)
  - Автоматическая генерация slug-имен
  - Поддержка изображений для категорий
  - Вложенность категорий (родительские → дочерние)

- **Товары**:
  - Привязка к категориям и подкатегориям
  - Поддержка изображений в 3-х размерах (оригинал, среднее, маленькое)
  - Ценообразование с поддержкой десятичных значений
  - Автоматические slug-имена
  - Даты создания и обновления

#### 2. **Корзина покупок**
- **Полный CRUD функционал**:
  - Добавление товаров в корзину
  - Изменение количества товаров
  - Удаление отдельных товаров
  - Полная очистка корзины
- **Автоматические расчеты**:
  - Подсчет общего количества товаров
  - Расчет итоговой суммы заказа
  - Отображение стоимости по позициям
- **Изоляция данных**: Каждый пользователь видит только свою корзину

#### 3. **Аутентификация и авторизация**
- **JWT (JSON Web Tokens)**:
  - Получение access/refresh токенов
  - Обновление access токенов
  - Защищенные эндпоинты
- **Разграничение прав доступа**:
  - Публичные эндпоинты (категории, товары)
  - Приватные эндпоинты (корзина) только для авторизованных пользователей
  - Административный доступ через Django Admin

#### 4. **API Фичи**
- **Пагинация**: Стандартная пагинация для всех списков
- **Фильтрация**: Фильтрация товаров по категориям
- **Поиск**: Full-text поиск по названиям товаров
- **Сортировка**: Сортировка по цене и дате создания
- **Валидация**: Встроенная валидация данных
- **Обработка ошибок**: Стандартизированные JSON-ответы об ошибках

#### 5. **Документация и тестирование**
- **Swagger UI**: Интерактивная документация API
- **ReDoc**: Альтернативная документация
- **Автотесты**: Покрытие тестами ключевых методов
- **Фикстуры**: Предзагруженные тестовые данные

```bash
git clone git@github.com:BaikNadia/test_shop_project.git
cd shop_project
```

### Шаг 2: Создание виртуального окружения
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux/Mac
python3 -m venv venv
source venv/bin/activate
```

### Шаг 3: Установка зависимостей
```bash
pip install -r requirements.txt
```

### Шаг 4: Настройка базы данных
```bash

python manage.py makemigrations

# Применение миграций
python manage.py migrate
```

## 🔌 API Endpoints

### 🔐 Аутентификация
| Метод | Endpoint | Описание | Требует авторизации |
|-------|----------|----------|---------------------|
| POST | `/api/token/` | Получение JWT токенов | ❌ |
| POST | `/api/token/refresh/` | Обновление access токена | ❌ |

### 📂 Категории
| Метод | Endpoint | Описание | Требует авторизации |
|-------|----------|----------|---------------------|
| GET | `/api/categories/` | Список родительских категорий с подкатегориями | ❌ |

| GET | `/api/categories/?page_size=5` | Изменение размера страницы | ❌ |

### 🛒 Товары
| Метод | Endpoint | Описание | Требует авторизации |
|-------|----------|----------|---------------------|
| GET | `/api/products/` | Список всех товаров | ❌ |
| GET | `/api/products/?category=2` | Фильтрация по категории | ❌ |
| GET | `/api/products/?search=iphone` | Поиск по названию | ❌ |
| GET | `/api/products/?ordering=price` | Сортировка по цене (возр.) | ❌ |
| GET | `/api/products/?ordering=-price` | Сортировка по цене (убыв.) | ❌ |

| POST | `/api/cart/items/` | Добавление товара в корзину | ✅ |
| PUT | `/api/cart/items/{id}/` | Изменение количества товара | ✅ |
| DELETE | `/api/cart/items/{id}/delete/` | Удаление товара из корзины | ✅ |
| POST | `/api/cart/clear/` | Полная очистка корзины | ✅ |

## 🗄️ База данных

### Схема базы данных
```sql
-- Категории (иерархическая структура)
Category
├── id (PK)
├── name (VARCHAR)
├── slug (VARCHAR, UNIQUE)
├── image (VARCHAR)
├── parent_id (FK to Category, NULL для родительских)
└── timestamps

-- Товары
Product
├── id (PK)
├── name (VARCHAR)
├── slug (VARCHAR, UNIQUE)
├── category_id (FK to Category)
├── price (DECIMAL)
└── timestamps

-- Изображения товаров
ProductImage
├── id (PK)
├── product_id (FK to Product)
├── original (VARCHAR)
├── medium (VARCHAR)
├── small (VARCHAR)
└── timestamps

-- Корзины пользователей
Cart
├── id (PK)
├── user_id (FK to User, UNIQUE)
└── timestamps

-- Элементы корзины
CartItem
├── id (PK)
├── cart_id (FK to Cart)
├── product_id (FK to Product)
├── quantity (INTEGER)
└── timestamps
```

```python
import requests

# 1. Получить список категорий
response = requests.get('http://127.0.0.1:8000/api/categories/')

```

### Сценарий 2: Работа с корзиной
```python
import requests

# 1. Получить токен
auth_response = requests.post('http://127.0.0.1:8000/api/token/', {
    'username': 'testuser',
    'password': 'testpass123'
})
token = auth_response.json()['access']

headers = {'Authorization': f'Bearer {token}'}

# 2. Добавить товары в корзину
requests.post('http://127.0.0.1:8000/api/cart/items/', 
    json={'product_id': 1, 'quantity': 2},
    headers=headers
)

# 3. Получить корзину
cart_response = requests.get('http://127.0.0.1:8000/api/cart/', headers=headers)
cart = cart_response.json()

print(f"Товаров в корзине: {cart['total_items']}")
print(f"Общая сумма: {cart['total_price']} руб.")
```
